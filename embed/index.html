Paste this into your site's HTML where you want the calculator to appear. The iframe resizes automatically to fit its content.

Using a CMS? Add an HTML block and paste the code into it — in WordPress it's the “Custom HTML” block, in Squarespace a “Code” block, in Ghost or Substack an “HTML” card. Paste into the HTML block, not the visual/rich-text editor, which can strip the <script> that auto-sizes the calculator.
